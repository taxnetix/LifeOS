What it is

Not an app. A repository that runs itself.

LifeOS has no server, no database and no front end. The repository is the product, the agent is the runtime, and plain files on disk are the state — readable in ten years, by someone who is not you, on a laptop with no internet. You drop a document in a folder; everything else is the system's job.

It runs on a loop

Change detection is a script, not a reasoning step, so an idle heartbeat costs almost nothing. It notices an elapsed cadence, an expiring policy or a stale rulebook — not just a new file.

Every number traces to a page

Each record carries its source document hash, exact locator, extraction method and confidence. Below the floor, a figure becomes a question instead of an entry.

Nothing personal leaves the machine

A hook blocks any outbound call carrying an ID number, an account number or a name from your profile. It is a mechanism, not a policy — so it holds even when an agent is wrong.

Unknown is a real answer

There is a gaps register. No placeholders, no plausible guesses, and no zero standing in for "we didn't look".

It maintains itself

Agents file issues about the system — a bank changed its statement layout, a tax table is past its refresh interval — and never about your life. The same hook enforces that line.

It can grow itself

One command scaffolds a new domain from the charter template, and the next heartbeat picks it up with zero changes to the orchestrator. Proven, not asserted.

The Life File

The document you hand your family

Everything they need on the worst day, in three audience tiers. No passwords, PINs or safe codes at any tier — LifeOS prints the pointer, never the secret.

First 48 Hours

Meant to be findable. Who to call, funeral wishes, where the will is, and the cash reachable in the first thirty days. No identifiers at all.

Executor Pack

Policies to claim, accounts, assets, debts, trusts and the digital estate — with every identifier masked to its last four digits.

Sealed Annexure

Full identifiers, for the executor alone. Must be asked for explicitly, watermarked, and every generation is written to the audit log.

Its headline section is “What my family will not find.”

The unsigned will. The missing title deed. The suretyship nobody knew about. A Life File that showed only what is known would be a comfortable lie — the gaps are the reason to read it while there is still time to act.

What it finds

Things no single document says

Each of these needed two or more documents read together. Every figure below is from the project's fully fictional demo vault.

Solvent, with R5 983 974 to spare — and the family can reach R30 000 in the first thirty days.

0.7 months of household spending. Bank accounts freeze at death, including joint accounts. Group life takes weeks. Anything falling into the estate takes months. An estate can be comfortably solvent and still leave a family unable to buy groceries.

Income protection is over-insured by R55 000 a month.

Employer cover and a personal policy together exceed the aggregate ceiling SA insurers underwrite to, so up to R15 408 a year of premium may be buying nothing — and employer cover ends with the job, so the answer is usually to reduce the personal policy, not drop it.

R1.8m is nominated away from the will's heir.

A beneficiary nomination overrides the will for that asset, and neither document mentions the other. Often deliberate — but it should be a decision, not a surprise.

An interest-free loan to the family trust costs R53 500 a year in donations tax.

Section 7C treats the interest forgone as a donation, payable by the lender personally, in cash, every year the loan stays interest-free. Nothing on the loan account says so.

Powered by the platform

Where LifeOS stops, IntelliTax starts

LifeOS deliberately never files. It reads documents, keeps ledgers, computes headroom and tracks deadlines — then says this needs a registered practitioner. IntelliTax is where that boundary can be crossed deliberately: South Africa's intelligent tax compliance platform, for SARS directives, tax certificates, Recognition of Transfer, employer reconciliation and bulk volumes.

GraphQL API

One typed endpoint over the whole platform — taxpayers, funds, employers, directives, certificates, billing — for deterministic calls from code.

MCP server

Every GraphQL query and mutation exposed as an MCP tool, so an agent stack acquires tax capability as configuration rather than as a client library.

Agent-to-agent

IntelliTax agents addressable by other agents, so tax administration becomes a step inside a wider automation rather than a destination someone navigates to.

This is a documented integration path, not a shipped feature.

LifeOS carries an intellitax skill describing the seam and what it would require — an account, an active subscription, billing, a service account and an API key. No IntelliTax client ships with LifeOS. Filing would remain human-gated, and an API key would live in your environment, never in the vault.

Unzip it and open the folder in Claude Code or Claude CoWork. The agents, commands and skills are just files in the repository, so they are there the moment it opens — nothing to install or register.

Run /lifeos-init first. The Python tools need the setup on the right for parsing and PDFs; without them the agents still read, reason and write the vault.

Clone it, with the toolchain

cd LifeOS

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm install

# then, in Claude Code

# memory/

Three tiers, owned by `memory-keeper`, all hand-editable — you are
expected to edit them, and `/consolidate` must preserve your edits.

- `short/` — this session and the last 7 days
- `medium/` — about 90 days: active projects, pending deadlines, promises
- `long/` — durable: preferences, standing instructions, decisions, patterns

`audit.jsonl` records every promotion, demotion and expiry, so memory is
never a black box.

# proposed/

**Everything waiting on you.**

Agents read, analyse, recommend and draft. They do not send, submit,
transact or delete. Anything irreversible or externally visible lands here
and waits.

- `issues/` — GitHub issue drafts. `/issues push` files the approved ones.
- `rejected/` — records that failed schema validation, with the error.
- `low-confidence/` — extractions below the ledger's confidence floor.
